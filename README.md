# 📈 Aramco Stock Analysis using Python

This project uses [yfinance](https://github.com/ranaroussi/yfinance) to pull real-time data for **Saudi Aramco (2222.SR)** and visualizes key metrics.

## ✅ Features

- Get stock info like **country** and **sector**
- Download full **price history**
- Display **volume on first trading day**
- Visualize price breakdown using a **pie chart**
